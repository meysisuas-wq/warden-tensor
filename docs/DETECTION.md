# Detection Models Guide

## Object Detection
YOLO v8-based detection for security-relevant objects:
- Person, Vehicle, Baggage, Weapons

## Face Recognition
Identify authorized personnel and watchlist:
1. Registration — Encode known faces
2. Detection — Extract from frames
3. Matching — Compare embeddings
4. Alert — Flag watchlist matches

## License Plate Recognition
Vehicle access control:
- Indonesian plate format support
- Real-time at 15 FPS
- Access control integration

## Motion Detection
Background subtraction:
- Adaptive background model
- Configurable sensitivity
- Region-based analysis
